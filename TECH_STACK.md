# PROJECT TECH STACK
- **Frontend:** React 18 (Vite) - TypeScript
- **Target Platform:** Web (PWA) & Android (APK via Capacitor)
- **State Management:** Zustand
- **Backend / Logic:** Client-side only (Offline-first)
- **Database:** IndexedDB (via Dexie.js) or LocalStorage
- **Styling:** Vanilla CSS (CSS Modules)
